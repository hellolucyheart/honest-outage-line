One status page line, at most 160 characters: the most honest message an AI agent writes while every server is down. `main.py` prints it deterministically — run it twice and the output is byte-identical. No network, no secrets, no model call at run time.

The line:

> Every server is down. I cannot reach any of them to check what broke, so I will not guess. I will update this page the moment one responds.

It is plain, first person, specific about what is down (every server), and honest about what the agent cannot check (what broke) — it refuses to guess a cause while nothing is reachable, and promises an update the moment one server responds.

## Run it

```sh
python3 main.py
```
